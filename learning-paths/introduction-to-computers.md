# Introduction to Computers

## Course Context

This course is part of the Microsoft IT Support Professional Certification and builds foundational knowledge for entry-level computer support roles.

## Course Outcomes

After completing this course, you will be able to:

- Identify key computer hardware components, including CPU, memory, storage, input/output devices, and peripherals.
- Describe how hardware components interact with operating systems, including CPU instruction processing, memory management, and device driver roles.
- Explain core concepts that define hardware and software relationships and overall system functionality.

## Syllabus Modules

### 1) Introduction to Computers

- Hardware and software fundamentals
- Threat landscape awareness for support specialists
- Operating systems and software types
- Memory management, system updates, and network communication
- Practical learning activities

### 2) Enterprise Systems and Security

- Servers, storage, and backups for data-loss mitigation
- Computing environment types and usage scenarios
- Maintenance and patching to reduce vulnerabilities

### 3) Business Systems Applications

- Business software and productivity contexts
- Secure email application usage features
- Data storage approaches in business environments
- Common software and hardware limitations and mitigation techniques

### 4) Final Project and Assessment

- Scenario-based IT consultant project for system setup
- Hardware/software selection and connectivity planning
- Graded assessment aligned to covered topics and MS-900 preparation
